วิธีใช้
1. เปิด index.html ด้วย Chrome หรือ Edge เพื่อดูเว็บไซต์
2. เปิดไฟล์ด้วยโปรแกรมแก้ไขข้อความเพื่อเปลี่ยน YOUR NAME ประวัติ ทักษะ ประสบการณ์ อีเมล และชื่อแบรนด์
3. ภาพป่าและภาพบุคคลเชื่อมจากเว็บไซต์อ้างอิงเพื่อแสดงตัวอย่างการจัดวาง ต้องใช้อินเทอร์เน็ตในการโหลดภาพ เปลี่ยนเป็นภาพของคุณก่อนเผยแพร่
4. ปกผลงานทั้ง 4 ชิ้นเป็นข้อความตัวอย่าง ไม่ใช่ผลงานจริง เปลี่ยนเป็นภาพผลงานของคุณ และแก้ data-title / data-description ของแต่ละปุ่ม
5. CSS อยู่ใน <style> และ JavaScript อยู่ใน <script> ภายในไฟล์เดียว ไม่ต้องติดตั้งโปรแกรมเสริม
